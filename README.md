# SOC Investigation Portfolio

## Overview

Welcome to my SOC Investigation Portfolio. This repository showcases hands-on Security Operations Center (SOC) investigations performed in a controlled lab environment using real-world attack scenarios. Each investigation follows the SOC incident response lifecycle, including detection, analysis, IOC extraction, threat hunting, MITRE ATT&CK mapping, and remediation.

The purpose of this portfolio is to demonstrate practical SOC Analyst skills in log analysis, incident investigation, malware analysis, phishing investigations, and threat detection.


## Objectives

- Detect and investigate cybersecurity incidents
- Analyze Windows and Sysmon logs
- Perform phishing email investigations
- Conduct malware behavior analysis
- Extract Indicators of Compromise (IOCs)
- Map adversary behavior to the MITRE ATT&CK framework
- Document incident response activities
- Develop detection rules and mitigation recommendations
